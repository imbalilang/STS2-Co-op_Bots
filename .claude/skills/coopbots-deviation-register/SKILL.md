# 偏离登记（S6）

完整规范在 `AGENT.md` §5 **S6** 与 §6 偏离登记表。本文件是入口；冲突时以 `AGENT.md` 为准。

## 触发

- 你**引入**了一处上游没有的行为；
- 你**发现**我们有一处和上游不一样（不管是谁加的）；
- 你正想加一条上游没有的拒绝逻辑 —— **先停下来读 R4**。

## R4：不许自造"门"

> 上游没有的拒绝逻辑不要加；**只有「可执行性」可以拒绝**
> （牌不在手里 / 打不出去 / 药水没了 / 席位不能行动）。

已量过：自造的 `HasUncertainRisk`、`Boundaries.Count > 0`、逐步漂移拒绝、边界拒绝 ——
**每一个都单独让剧本跑不完。**

所以"我不想让这种情况发生"**不是**加拒绝的理由。真需要偏离，就走本 skill 登记，
而不是悄悄加一道闸。

## 步骤

### 1. 代码注释写三段式

在被改的地方写明：

```
上游怎么做：<原文行为>
我们怎么做：<我们的行为>
为什么：<用户要求 / 联机约束 / 设计，以及出处>
```

不要只写"上游不一样"。**"为什么"必须能指到人、指到日期或指到一条设计约束。**

### 2. `AGENT.md` §6 追加一行

| 偏离 | 理由 | 来源 |
|---|---|---|

三个格子都要填。"来源"写用户 + 日期、或"设计"、或"实机管线"。
不写"来源"的偏离，下一个 session 会当成 bug 修掉。

## 完成判据

**任何"上游没有"的东西都能在 `AGENT.md` §6 找到出处。**
反过来说：§6 里找不到的东西，要么是遗漏（补登记），要么是 bug（修掉）。

## 和 S1 的关系

S1（上游序列审计）每一处判为**"有意偏离"**的差量，都必须在这里有出处。
S1 找不到出处的差量 = **遗漏**，不是偏离。

## 例子（§6 已有的形态）

- 「未建模的 `OnPlay` = boundary（跳过该牌）」→ 上游行为；估算过的牌不能进剧本 → 用户 2026-09-20
- 「逐步漂移 / 边界漂移**只记录不拒绝**」→ 上游不逐动**比对** → 用户 2026-09-20
- 「哨兵文件 `mods/CoopBots/live-test.flag` 触发无人值守开局」→ 经 Steam 启动时游戏不是本进程子进程，
  环境变量传不进去 → 实机管线
