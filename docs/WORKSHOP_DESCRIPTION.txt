[h1]Co-op Bots / 联机机器人[/h1]
为《杀戮尖塔 2》的官方多人房间加入 AI 队友。Bot 使用真实玩家席位，动作通过游戏队列同步；所有真人需安装相同版本。

[h2]最新更新 / Latest：0.39.3（2026-10-24）[/h2]
[list]
[*]修复真人奖励界面导致 Bot 不跟随选房，以及自动回合握手误清选牌计划。
[*]真人仍行动时采用短预算比较，从已结算盘面验证续招，减少完整重搜；Bot 可在真人结束回合前穿插出牌。
[*]补齐控制权交回、真人集火和急救续招，修复宝箱奖励及托管事件的多人同步。
[/list]
新增17个回归场景及31项故障注入红绿验证；发布构建验证收据随 GitHub Release 附件提供。尚未完成双客户端混合局实机验收，未验证实际延迟或胜率改善。
Mixed-table fixes cover room voting, automatic handshakes, shorter searches with continuation replay, control handback, manual focus, rescues, and treasure/event sync. Bots can play before humans end their turn. Release validation accompanies the GitHub Release; two-client gameplay and latency remain unverified.

[h2]玩法[/h2]
在官方多人大厅添加 Bot，并调整节奏与性能预算。
Flash / Pro / Cheated 共用算法；档位影响节奏与思考预算，Cheated 另有金币加成。
支持全 Bot 与真人/Bot 混合桌。联合规划考虑各席生命、共享易伤/虚弱、格挡与真人输入变化；局外可处理奖励、商店、事件、营地和路线建议。
战斗内核基于 CombatSolver 0.41.0，采用有界搜索和执行状态核对；局外构筑结合卡组结构、实际升级差分与资源启动。

[h2]依赖与兼容[/h2]
需要游戏 v0.111.0 与 RitsuLib 0.6.2+ 的兼容变体。请订阅并启用 RitsuLib，所有真人保持相同 MOD 版本。
本项目不随包分发游戏或 RitsuLib 程序集。手动安装时将 CoopBots.dll、CoopBots.Kernel.dll 和 mod_manifest.json 放入 mods/CoopBots。
多人同步或游戏版本变化可能需要更新兼容层；问题反馈请附 MOD/游戏版本和匿名化日志。

[h2]开源协作[/h2]
欢迎开发者及其 Agent 提交原生复现场景、性能证据和算法改进。全 Bot 基线保持路线与预算，真人行动时使用有界短比较；开发种子和留出种子分开，保留自然失败、卡死与异常尝试。不要用战斗胜率代替整塔通关率。
