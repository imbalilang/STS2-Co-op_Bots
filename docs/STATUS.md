# 当前状态与贡献方向（2026-10-25）

## 当前发布：0.40.0

0.40.0 汇总混合局后台执行、停牌恢复、结束准备与选择租约修复，导入内核仍为 CombatSolver **0.41.0**。真人结束前后保持同一完整锦标赛；默认 Pro / Cheated 使用全队约 1.5 秒的卡牌提交节奏，Flash 0.5 秒，真人结束后取消人为间隔并优先执行已有合法剧本。混合局后台按真人已结算输入比较当前盘面，全 Bot 保留严格执行及未来回合优化。0.39.3 的选房、自动握手、宝箱和事件同步修复保留；社区贡献内容见 [合入说明](COMMUNITY_PACKAGE_20261022.md)，完整变更见 [CHANGELOG](../CHANGELOG.md)。

项目所有者于 2026-10-25 明确确认当前最新候选已通过纯 Bot 局与人机混合局强度测试，并授权发布为 0.40.0。此结论来自所有者实测确认；当前未提供可公开的样本数、种子或胜率，不据此新增统计结论。此前文档中的未实机复测描述属于当时本地候选阶段，不代表此次发布仍未经过上述测试。

0.39.4 本地修复候选最近一次完整门禁为 **995 PASS**，含本轮 20 个新增场景和 21 项实际故障注入；这是版本升级前的历史工件证据。0.40.0 的构建、独立类型加载和一次未过滤完整回归在隔离发布克隆执行，本版实际门禁与双 DLL 身份以 GitHub Release 附件为准，旧门禁不替代新版本验证。

## 已修复路径与剩余搜索限制

混合局完整锦标赛、药水比较和实际根重放改为后台执行；主线程仍负责实际盘面捕获、执行校验和原生提交。药水库存及权限在捕获时冻结，取消工作不会在主线程等待。必要与可选预算分开，保存已结算前缀；无候选、结果消费与最终药水比较均有截止约束。真人结束准备不再当作材料输入取消搜索，收尾提前计算但提交仍等待真人结束；同一实体牌的死亡目标可局部修复，原生复活阶段可正常收尾。回合开始租约及时退休，普通真人输入撤销旧未来合同与质量证明，保留合法实体后缀和可在实际菜单校验的即时选择。

这些修复不等于所有后台搜索都能兑现：Bot 执行推进或新的真人材料输入仍可能使可选候选变旧，部分旧剧本来自尚未完成完整比较的已结算前缀。当前没有同根配对证据量化此限制对棋力的影响，也未公开主线程捕获、GC、FPS 或拖牌延迟的量化对照。真人未来动作仍采用既有压力情形，不能把混合桌结果直接等同于全 Bot 全队联合未来选择。历史四次 turn-start 合同拒绝的具体轴仍未确证；新增诊断和其他选择租约修复不代表这四次历史事件已完整复现。

## 历史诊断：结束后额外长考（2026-10-25，修复前）

归档完整混合局运行较早的 0.39.4 本地 975 项门禁工件，最终在第三幕 46 层女王战自然失败。102 条必要搜索关闭记录中 58 条因真人输入取消：46 次打牌、8 次结束回合、3 次药水、1 次撤销；取消前累计 114.53 秒墙钟，部分与执行并行。79 次缓存里 51 次来自尚未完成整体比较的原生前缀，不能称作完整锦标赛胜者。290 次后台比较仅 1 次采用新结果，其中 233 次因前台游标或新输入变旧；24 次正常消费也可能代表基线已胜或没有更好方案，不能一概记作失败。993 次出牌均走内核，未观察到旧算法接管。该单局支持搜索结果兑现受干扰，不能量化棋力下降或把团灭归因于该问题；上述数字不是 0.40.0 修复后的测量。

## 历史诊断：画面卡顿与预算耗尽（2026-10-25，修复前）

更早鬼祟珊瑚群日志中，必要搜索与后台共用 9600ms 回合额度；真人输入取消后仅余 32/22/3ms，无候选而停等。必要与可选预算拆分、及时部署无药胜利、前缀保留和有界恢复均已合入。早期 967 项、后续 975 项与最终本地 995 项门禁属于不同冻结工件，不能互相替代；历史本地收据保存在维护者私有 work 目录，不随源码提供。

## 历史样本问题与当前限制

历史五局中的第 1、2、3、5 局有具名状态差异。涉及牌来源标记、持续时间边界、生命周期缓存等；部分 Boss 续演还会因资格或物理牌引用失效被丢弃。它们对本批团灭的具体贡献尚未证明，也没有足够原生证据将其一概豁免为无害差异。

历史第 4 局有回合开始选牌预测无法自动应答的诊断和续演资格不足，不能仅由这些日志认定实机选牌失败。应先保存实际菜单、原生答案和后继状态，再判断属于预测覆盖还是执行缺陷。

项目所有者已确认当前候选通过全 Bot 与混合桌强度测试；未提供可公开的样本数、种子和胜率，不能由此量化全 Bot A10 **50%** 整塔通关目标。不同桌面配置仍需分别统计。

## 欢迎贡献

1. **模拟与执行一致性**：将具名差异收缩为原生短场景，对照真实游戏动作；修复后保留跨回合、父子分支与物理牌身份验证。避免通过删除状态检查掩盖未解释差异。
2. **固定成本下的有效搜索**：提高可用候选覆盖、减少无效续演和重复捕获，记录主线程延迟、分配、GC 与超时；四席共享既有决策预算，High 并发基线为 6。
3. **长战斗与团队防御**：结合席位生存、Boss 压力、药水时机与有效出牌顺序验证收益。真实原生盘面和相同预算对照优先于孤立评分。
4. **局外构筑**：检查资源启动、持续输出、防御、升级、删牌和事件选择，用完整爬塔战损及终局检验局部估值变化。
5. **混合桌失效处理**：真人输入后的可执行续打、后台合并比较、提交合同与响应成本，独立于全 Bot 统计。

全 Bot 基线保持路线选择与既有搜索预算，混合局真人结束前后保持同一完整锦标赛；知识恶魔统一瓦解。改变这些基线的实验须明确单独标识，避免把额外搜索资源当作算法提升。
